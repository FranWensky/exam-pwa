# Сессия

Мобильное PWA для подготовки к экзаменам. Теория и тренировки доступны после первой загрузки по интернету. На iPhone откройте сайт в Safari, выберите «Поделиться» → «На экран “Домой”» и включите «Открывать как веб-приложение», если Safari показывает этот переключатель.

В настройках можно добавить карточки строками `Вопрос | Ответ`, сохранить резервную копию или перенести свои карточки на другое устройство. Приложение хранит дополнения в браузере и включает их в резервную копию вместе с исходной теорией и карточками. Восстановление объединяет дополнения с опубликованной базой по темам.

## Импорт

Из каталога приложения запустите `python tools/import_materials.py --source-dir <каталог>`. Скрипт читает `materials.txt`, если он есть, или три исходных конспекта, и записывает `data.json`. Если файл по матанализу находится отдельно, передайте путь через `--matan`. HTML по линейной алгебре используется при наличии для сохранения разметки.

В едином файле используются заголовки `# Предмет`, `## Раздел`, `### Тема` и `#### Карточки`. Для программирования указывайте `## Билет`. Карточки пишутся по одной на строку в формате `Вопрос | Ответ`. Статические файлы публикуются из корня ветки `main`.

Рисунки к § 7 лежат в `figures/` в исходном PNG. Остальные схемы ЛАиАГ создаёт `python tools/draw_figures.py`. Расположение и подписи задаются в `tools/figures.py`; при импорте они добавляются в `data.json`. Сервис-воркер сохраняет рисунки для чтения офлайн.
